Proyectos

01

Aplicación Móvil Institucional Destacado gubernamental

Aplicación móvil multiplataforma desarrollada durante mi práctica profesional para una institución gubernamental. Participé en el desarrollo y despliegue de una solución utilizada por personal de la institución, compuesta por tres módulos, uno orientado a servicios legales y dos destinados a procesos internos. La aplicación fue desarrollada utilizando Angular, Ionic, Capacitor y TypeScript, implementando interfaces responsivas, autenticación de usuarios y consumo de servicios mediante APIs. Como parte del proyecto integré flujos de Power Automate con SharePoint Online, permitiendo consultar el estado de trámites directamente desde la aplicación sin necesidad de atención presencial, mejorando la disponibilidad y accesibilidad de los servicios digitales.

Ionic Angular Capacitor TypeScript HTML / CSS Power Automate REST APIs

02

App de Agenda Institucional gubernamental

Aplicación empresarial desarrollada con Power Apps para optimizar la gestión de reuniones institucionales. La solución permite administrar agendas, consultar disponibilidad y organizar actividades mediante una interfaz sencilla e integrada con el ecosistema Microsoft. Implementé la lógica de negocio utilizando Power Fx e integré la aplicación con Microsoft 365 Outlook mediante flujos de Power Automate, automatizando la creación y administración de reuniones institucionales y reduciendo tareas manuales dentro del proceso administrativo.

Power Apps Power Fx Power Automate Microsoft 365 Outlook
2026 · Institución gubernamental

Sistema Web de Gestión para Clínica personal

Sistema web desarrollado bajo metodología Scrum para la administración de pacientes, expedientes clínicos, citas médicas e inventario. Participé en el desarrollo Full-Stack implementando una arquitectura cliente-servidor con React, Vite y TypeScript para el frontend, y Node.js con APIs REST para el backend. Sistema de Ventas Web — Papelería equipo

Aplicación web desarrollada en equipo para la administración de ventas e inventario de una papelería. Participé en el desarrollo del frontend con React, Vite y TypeScript, así como en la integración con un backend desarrollado en Node.js y APIs REST, conectado a una base de datos MySQL. Implementé funcionalidades relacionadas con el proceso de facturación, generación automática de comprobantes en formato PDF, validaciones de usuarios y consumo de servicios. El proyecto fue desarrollado utilizando Git y GitHub para el trabajo colaborativo y Postman para las pruebas y documentación de APIs.

React Vite TypeScript Node.js REST APIs JWT HTML/CSS MySQL GitHub Postman PDF

E-commerce — ASP.NET académico
